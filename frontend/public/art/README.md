# Static character artwork

These WebP portraits are derived from this project's existing `public/characters/*.png` illustrations. The baked checkerboard backgrounds were removed, the images resized, and the results compressed for the interface. They are static cover art, not sprite animation frames or 3D models.

The featured character, roster cards, and profile portraits never animate these images. Jin-Woo's separate 3D preview loads the user-supplied official Sketchfab collection only when requested.
